# latintype

Type and read real Latin, with the scansion shown over every line. Live at [latintype.com](https://latintype.com).

## Features

- Typing modes: zen, passage, time attack and a daily challenge
- Read mode with scansion, part-of-speech colours, dictionary lookup, annotation, and PDF and LaTeX export
- 21 authors, from Catullus to Virgil
- Six colour palettes and a choice of fonts for the Latin
- No accounts

## Running it

```bash
npm install
npm run dev
```

`npm run deploy` builds nothing by itself. Run `npm run build` first, then deploy to publish `dist` to GitHub Pages.
